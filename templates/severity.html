Important scientific limitation

This Version 3.5 module performs GrabCut foreground refinement with adaptive HSV seeds and color-threshold segmentation of brown/dark pixels inside an automatically isolated foreground region. The percentage is a pixel-mask proportion, not a validated biological severity score. Shadows, lighting, background foliage, blur, yellow lesions, and symptoms whose color resembles healthy tissue can affect the result. YOLO is used only to provide disease-class context; its bounding boxes do not determine this percentage. Validate the masks against expert-labelled pixel masks before reporting accuracy or using the value for agricultural decisions. For reliable general-purpose measurement, train and evaluate a dedicated segmentation model using pixel-level lesion annotations.
